# ✈️ Panafrique – Flight Information 
* Application en ligne : 

Panafrique est une application web qui simule un **Flight Information Display System (FIDS)**, permettant d'afficher les informations des vols en temps réel dans une interface claire, moderne et responsive.

## 🚀 Fonctionnalités

* 🛫 Affichage des vols au départ et à l'arrivée
* ⏰ Heure de départ et d'arrivée
* 📍 Destination et provenance
* 🛬 Statut des vols (À l'heure, Embarquement, Retardé, Annulé, etc.)
* 🔎 Recherche et filtrage des vols
* 📱 Interface responsive adaptée aux écrans de toutes tailles

## 🛠️ Technologies utilisées

* HTML5
* CSS3
* JavaScript

## 📦 Installation

```bash
git clone https://github.com/reineekoueth/Panafrique.git
cd Panafrique
```

Si le projet utilise Node.js :

```bash
npm install
npm run dev
```
